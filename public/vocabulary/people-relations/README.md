# People, family, and relationships visuals

These sprite sheets were generated for Constlingo with OpenAI's built-in image
generation tool on 2026-08-04. They use original, generic characters and do not
depict or intentionally imitate any existing franchise character or actor.

The application uses the 50 individually cropped WebP files in `items/`. Their
boundaries were measured from the actual gutters in each generated sheet; the
source sheets below remain only as non-destructive generation records.

The sheets follow the vocabulary order in `spanish_first_1000_words_jp.csv`:

- `people.webp`: items 566-575
- `family.webp`: items 576-585
- `relationships.webp`: items 586-595
- `social-school.webp`: items 596-601 and 604-605
- `customer-teacher.webp`: items 602-603
- `professions.webp`: items 606-613
- `cooks.webp`: items 614-615

Generation brief: flat editorial educational illustrations, warm paper texture,
the app's off-white/coral/teal/mustard/ink palette, culturally diverse original
people, clear centered subjects, and no text, logos, trademarks, or watermarks.
